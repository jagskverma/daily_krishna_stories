1. gopa-vṛddhāś ca gopyaś ca tad upākarṇya vismitāḥ /
menire deva-pravarau kṛṣṇa-rāmau vrajaṃ gatau
2. tataḥ prāvartata prāvṛṭ sarva-sattva-samudbhavā /
vidyotamāna-paridhir visphūrjita-nabhas-talā
3. sāndra-nīlāmbudair vyoma sa-vidyut-stanayitnubhiḥ /
aspaṣṭa-jyotir ācchannaṃ brahmeva sa-guṇaṃ babhau
4. aṣṭau māsān nipītaṃ yad bhūmyāś coda-mayaṃ vasu /
sva-gobhir moktum ārebhe parjanyaḥ kāla āgate
5. taḍidvanto mahā-meghāś caṇḍa -śvasana -vepitāḥ /
prīṇanaṃ jīvanaṃ hy asya mumucuḥ karuṇā iva
6. tapaḥ-kṛśā deva-mīḍhā āsīd varṣīyasī mahī /
yathaiva kāmya-tapasas tanuḥ samprāpya tat-phalam
7. niśā-mukheṣu khadyotās tamasā bhānti na grahāḥ /
yathā pāpena pāṣaṇḍā na hi vedāḥ kalau yuge
8. śrutvā parjanya-ninadaṃ maṇḍukāḥ sasṛjur giraḥ /
tūṣṇīṃ śayānāḥ prāg yadvad brāhmaṇā niyamātyaye
9. āsann utpatha-gāminyaḥ kṣudra-nadyo 'nuśuṣyatīḥ /
puṃso yathāsvatantrasya deha-draviṇa -sampadaḥ
10. haritā haribhiḥ śaṣpair indragopaiś ca lohitā /
ucchilīndhra-kṛta-cchāyā nṛṇāṃ śrīr iva bhūr abhūt
11. kṣetrāṇi śaṣya-sampadbhiḥ karṣakāṇāṃ mudaṃ daduḥ /
māninām anutāpaṃ vai daivādhīnam ajānatām
12. jala-sthalaukasaḥ sarve nava-vāri-niṣevayā /
abibhran ruciraṃ rūpaṃ yathā hari-niṣevayā
13. saridbhiḥ saṅgataḥ sindhuś cukṣobha śvasanormimān /
apakva-yoginaś cittaṃ kāmāktaṃ guṇa-yug yathā
14. girayo varṣa-dhārābhir hanyamānā na vivyathuḥ /
abhibhūyamānā vyasanair yathādhokṣaja-cetasaḥ
15. mārgā babhūvuḥ sandigdhās tṛṇaiś channā hy asaṃskṛtāḥ /
nābhyasyamānāḥ śrutayo dvijaiḥ kālena cāhatāḥ
16. loka-bandhuṣu megheṣu vidyutaś cala-sauhṛdāḥ /
sthairyaṃ na cakruḥ kāminyaḥ puruṣeṣu guṇiṣv iva
17. dhanur viyati māhendraṃ nirguṇaṃ ca guṇiny abhāt /
vyakte guṇa-vyatikare 'guṇavān puruṣo yathā
18. na rarājoḍupaś channaḥ sva-jyotsnā-rājitair ghanaiḥ /
ahaṃ-matyā bhāsitayā sva-bhāsā puruṣo yathā
19. meghāgamotsavā hṛṣṭāḥ pratyanandañ chikhaṇḍinaḥ /
gṛheṣu tapta-nirviṇṇā yathācyuta-janāgame
20. pītvāpaḥ pādapāḥ padbhir āsan nānātma-mūrtayaḥ /
prāk kṣāmās tapasā śrāntā yathā kāmānusevayā
21. saraḥsv aśānta-rodhaḥsu nyūṣur aṅgāpi sārasāḥ /
gṛheṣv aśānta-kṛtyeṣu grāmyā iva durāśayāḥ
22. jalaughair nirabhidyanta setavo varṣatīśvare /
pāṣaṇḍinām asad-vādair veda-mārgāḥ kalau yathā
23. vyamuñcan vāyubhir nunnā bhūtebhyaś cāmṛtaṃ ghanāḥ /
yathāśiṣo viś-patayaḥ kāle kāle dvijeritāḥ
24. evaṃ vanaṃ tad varṣiṣṭhaṃ pakva-kharjura-jambumat /
go-gopālair vṛto rantuṃ sa-balaḥ prāviśad dhariḥ
25. dhenavo manda-gāminya ūdho-bhāreṇa bhūyasā /
yayur bhagavatāhūtā drutaṃ prītyā snuta-stanāḥ
26. vanaukasaḥ pramuditā vana-rājīr madhu-cyutaḥ /
jala-dhārā girer nādād āsannā dadṛśe guhāḥ
27. kvacid vanaspati-kroḍe guhāyāṃ cābhivarṣati /
nirviśya bhagavān reme kanda-mūla-phalāśanaḥ
28. dadhy-odanaṃ samānītaṃ śilāyāṃ salilāntike /
sambhojanīyair bubhuje gopaiḥ saṅkarṣaṇānvitaḥ
29. śādvalopari saṃviśya carvato mīlitekṣaṇān /
tṛptān vṛṣān vatsatarān gāś ca svodho-bhara-śramāḥ
30. prāvṛṭ-śriyaṃ ca tāṃ vīkṣya sarva-kāla-sukhāvahām /
bhagavān pūjayāṃ cakre ātma-śakty-upabṛṃhitām
31. evaṃ nivasatos tasmin rāma-keśavayor vraje /
śarat samabhavad vyabhrā svacchāmbv-aparuṣānilā
32. śaradā nīrajotpattyā nīrāṇi prakṛtiṃ yayuḥ /
bhraṣṭānām iva cetāṃsi punar yoga-niṣevayā
33. vyomno 'bbhraṃ bhūta-śābalyaṃ bhuvaḥ paṅkam apāṃ malam /
śaraj jahārāśramiṇāṃ kṛṣṇe bhaktir yathāśubham
34. sarva-svaṃ jaladā hitvā virejuḥ śubhra-varcasaḥ /
yathā tyaktaiṣaṇāḥ śāntā munayo mukta-kilbiṣāḥ
35. girayo mumucus toyaṃ kvacin na mumucuḥ śivam /
yathā jñānāmṛtaṃ kāle jñānino dadate na vā
36. naivāvidan kṣīyamāṇaṃ jalaṃ gādha-jale-carāḥ /
yathāyur anv-ahaṃ kṣayyaṃ narā mūḍhāḥ kuṭumbinaḥ
37. gādha-vāri-carās tāpam avindañ charad-arka-jam /
yathā daridraḥ kṛpaṇaḥ kuṭumby avijitendriyaḥ
38. śanaiḥ śanair jahuḥ paṅkaṃ sthalāny āmaṃ ca vīrudhaḥ /
yathāhaṃ-mamatāṃ dhīrāḥ śarīrādiṣv anātmasu
39. niścalāmbur abhūt tūṣṇīṃ samudraḥ śarad-āgame /
ātmany uparate samyaṅ munir vyuparatāgamaḥ
40. kedārebhyas tv apo 'gṛhṇan karṣakā dṛḍha-setubhiḥ /
yathā prāṇaiḥ sravaj jñānaṃ tan-nirodhena yoginaḥ
41. śarad-arkāṃśu-jāṃs tāpān bhūtānām uḍupo 'harat /
dehābhimāna-jaṃ bodho mukundo vraja-yoṣitām
42. kham aśobhata nirmeghaṃ śarad-vimala-tārakam /
sattva-yuktaṃ yathā cittaṃ śabda-brahmārtha-darśanam
43. akhaṇḍa-maṇḍalo vyomni rarājoḍu-gaṇaiḥ śaśī /
yathā yadu-patiḥ kṛṣṇo vṛṣṇi-cakrāvṛto bhuvi
44. āśliṣya sama-śītoṣṇaṃ prasūna-vana-mārutam /
janās tāpaṃ jahur gopyo na kṛṣṇa-hṛta-cetasaḥ
45. gāvo mṛgāḥ khagā nāryaḥ puṣpiṇyaḥ śaradābhavan /
anvīyamānāḥ sva-vṛṣaiḥ phalair īśa-kriyā iva
46. udahṛṣyan vārijāni sūryotthāne kumud vinā /
rājñā tu nirbhayā lokā yathā dasyūn vinā nṛpa
47. pura-grāmeṣv āgrayaṇair indriyaiś ca mahotsavaiḥ /
babhau bhūḥ pakva-śaṣyāḍhyā kalābhyāṃ nitarāṃ hareḥ
48. vaṇiṅ-muni-nṛpa-snātā nirgamyārthān prapedire /
varṣa-ruddhā yathā siddhāḥ sva-piṇḍān kāla āgate
