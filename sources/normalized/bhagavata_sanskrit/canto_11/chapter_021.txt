1. sve sve 'dhikāre yā niṣṭhā sa guṇaḥ parikīrtitaḥ /
viparyayas tu doṣaḥ syād ubhayor eṣa niścayaḥ
2. śuddhy-aśuddhī vidhīyete samāneṣv api vastuṣu /
dravyasya vicikitsārthaṃ guṇa-doṣau śubhāśubhau
3. dharmārthaṃ vyavahārārthaṃ yātrārtham iti cānagha /
darśito 'yaṃ mayācāro dharmam udvahatāṃ dhuram
4. bhūmy-ambv-agny-anilākāśā bhūtānāṃ pañca-dhātavaḥ /
ā-brahma-sthāvarādīnāṃ śārīrā ātma-saṃyutāḥ
5. vedena nāma-rūpāṇi viṣamāṇi sameṣv api /
dhātuṣūddhava kalpyanta eteṣāṃ svārtha-siddhaye
6. deśa-kālādi-bhāvānāṃ vastūnāṃ mama sattama /
guṇa-doṣau vidhīyete niyamārthaṃ hi karmaṇām
7. akṛṣṇa-sāro deśānām abrahmaṇyo 'sucir bhavet /
kṛṣṇa-sāro 'py asauvīra- kīkaṭāsaṃskṛteriṇam
8. karmaṇyo guṇavān kālo dravyataḥ svata eva vā /
yato nivartate karma sa doṣo 'karmakaḥ smṛtaḥ
9. dravyasya śuddhy-aśuddhī ca dravyeṇa vacanena ca /
saṃskāreṇātha kālena mahatvālpatayātha vā
10. śaktyāśaktyātha vā buddhyā samṛddhyā ca yad ātmane /
aghaṃ kurvanti hi yathā deśāvasthānusārataḥ
11. dhānya-dārv-asthi-tantūnāṃ rasa-taijasa-carmaṇām /
kāla-vāyv-agni-mṛt-toyaiḥ pārthivānāṃ yutāyutaiḥ
12. amedhya-liptaṃ yad yena gandha-lepaṃ vyapohati /
bhajate prakṛtiṃ tasya tac chaucaṃ tāvad iṣyate
13. snāna-dāna-tapo-'vasthā- vīrya-saṃskāra-karmabhiḥ /
mat-smṛtyā cātmanaḥ śaucaṃ śuddhaḥ karmācared dvijaḥ
14. mantrasya ca parijñānaṃ karma-śuddhir mad-arpaṇam /
dharmaḥ sampadyate ṣaḍbhir adharmas tu viparyayaḥ
15. kvacid guṇo 'pi doṣaḥ syād doṣo 'pi vidhinā guṇaḥ /
guṇa-doṣārtha-niyamas tad-bhidām eva bādhate
16. samāna-karmācaraṇaṃ patitānāṃ na pātakam /
autpattiko guṇaḥ saṅgo na śayānaḥ pataty adhaḥ
17. yato yato nivarteta vimucyeta tatas tataḥ /
eṣa dharmo nṛṇāṃ kṣemaḥ śoka-moha-bhayāpahaḥ
18. viṣayeṣu guṇādhyāsāt puṃsaḥ saṅgas tato bhavet /
saṅgāt tatra bhavet kāmaḥ kāmād eva kalir nṛṇām
19. kaler durviṣahaḥ krodhas tamas tam anuvartate /
tamasā grasyate puṃsaś cetanā vyāpinī drutam
20. tayā virahitaḥ sādho jantuḥ śūnyāya kalpate /
tato 'sya svārtha-vibhraṃśo mūrcchitasya mṛtasya ca
21. viṣayābhiniveśena nātmānaṃ veda nāparam /
vṛkṣa jīvikayā jīvan vyarthaṃ bhastreva yaḥ śvasan
22. phala-śrutir iyaṃ nṝṇāṃ na śreyo rocanaṃ param /
śreyo-vivakṣayā proktaṃ yathā bhaiṣajya-rocanam
23. utpattyaiva hi kāmeṣu prāṇeṣu sva-janeṣu ca /
āsakta-manaso martyā ātmano 'nartha-hetuṣu
24. natān aviduṣaḥ svārthaṃ bhrāmyato vṛjinādhvani /
kathaṃ yuñjyāt punas teṣu tāṃs tamo viśato budhaḥ
25. evaṃ vyavasitaṃ kecid avijñāya kubuddhayaḥ /
phala-śrutiṃ kusumitāṃ na veda-jñā vadanti hi
26. kāminaḥ kṛpaṇā lubdhāḥ puṣpeṣu phala-buddhayaḥ /
agni-mugdhā dhūma-tāntāḥ svaṃ lokaṃ na vidanti te
27. na te mām aṅga jānanti hṛdi-sthaṃ ya idaṃ yataḥ /
uktha-śastrā hy asu-tṛpo yathā nīhāra-cakṣuṣaḥ
28. te me matam avijñāya parokṣaṃ viṣayātmakāḥ /
hiṃsāyāṃ yadi rāgaḥ syād yajña eva na codanā
29. hiṃsā-vihārā hy ālabdhaiḥ paśubhiḥ sva-sukhecchayā /
yajante devatā yajñaiḥ pitṛ-bhūta-patīn khalāḥ
30. svapnopamam amuṃ lokam asantaṃ śravaṇa-priyam /
āśiṣo hṛdi saṅkalpya tyajanty arthān yathā vaṇik
31. rajaḥ-sattva-tamo-niṣṭhā rajaḥ-sattva-tamo-juṣaḥ /
upāsata indra-mukhyān devādīn na yathaiva mām
32. iṣṭveha devatā yajñair gatvā raṃsyāmahe divi /
tasyānta iha bhūyāsma mahā-śālā mahā-kulāḥ
33. evaṃ puṣpitayā vācā vyākṣipta-manasāṃ nṛṇām /
mānināṃ cāti-lubdhānāṃ mad-vārtāpi na rocate
34. vedā brahmātma-viṣayās tri-kāṇḍa-viṣayā ime /
parokṣa-vādā ṛṣayaḥ parokṣaṃ mama ca priyam
35. śabda-brahma su-durbodhaṃ prāṇendriya-mano-mayam /
ananta-pāraṃ gambhīraṃ durvigāhyaṃ samudra-vat
36. mayopabṛṃhitaṃ bhūmnā brahmaṇānanta-śaktinā /
bhūteṣu ghoṣa-rūpeṇa viseṣūrṇeva lakṣyate
37. yathorṇanābhir hṛdayād ūrṇām udvamate mukhāt /
ākāśād ghoṣavān prāṇo manasā sparśa-rūpiṇā
38. chando-mayo 'mṛta-mayaḥ sahasra-padavīṃ prabhuḥ /
oṃkārād vyañjita-sparśa- svaroṣmāntastha-bhūṣitām
39. vicitra-bhāṣā-vitatāṃ chandobhiś catur-uttaraiḥ /
ananta-pārāṃ bṛhatīṃ sṛjaty ākṣipate svayam
40. gāyatry uṣṇig anuṣṭup ca bṛhatī paṅktir eva ca /
triṣṭub jagaty aticchando hy atyaṣṭy-atijagad-virāṭ
41. kiṃ vidhatte kim ācaṣṭe kim anūdya vikalpayet /
ity asyā hṛdayaṃ loke nānyo mad veda kaścana
42. māṃ vidhatte 'bhidhatte māṃ vikalpyāpohyate tv aham /
etāvān sarva-vedārthaḥ śabda āsthāya māṃ bhidām /
māyā-mātram anūdyānte pratiṣidhya prasīdati
