1. ilāyām api bhāryāyāṃ vāyoḥ putryāṃ mahā-balaḥ /
putram utkala-nāmānaṃ yoṣid-ratnam ajījanat
2. uttamas tv akṛtodvāho mṛgayāyāṃ balīyasā /
hataḥ puṇya-janenādrau tan-mātāsya gatiṃ gatā
3. dhruvo bhrātṛ-vadhaṃ śrutvā kopāmarṣa-śucārpitaḥ /
jaitraṃ syandanam āsthāya gataḥ puṇya-janālayam
4. gatvodīcīṃ diśaṃ rājā rudrānucara-sevitām /
dadarśa himavad-droṇyāṃ purīṃ guhyaka-saṅkulām
5. dadhmau śaṅkhaṃ bṛhad-bāhuḥ khaṃ diśaś cānunādayan /
yenodvigna-dṛśaḥ kṣattar upadevyo 'trasan bhṛśam
6. tato niṣkramya balina upadeva-mahā-bhaṭāḥ /
asahantas tan-ninādam abhipetur udāyudhāḥ
7. sa tān āpatato vīra ugra-dhanvā mahā-rathaḥ /
ekaikaṃ yugapat sarvān ahan bāṇais tribhis tribhiḥ
8. te vai lalāṭa-lagnais tair iṣubhiḥ sarva eva hi /
matvā nirastam ātmānam āśaṃsan karma tasya tat
9. te 'pi cāmum amṛṣyantaḥ pāda-sparśam ivoragāḥ /
śarair avidhyan yugapad dvi-guṇaṃ pracikīrṣavaḥ
10. tataḥ parigha-nistriṃśaiḥ prāsaśūla-paraśvadhaiḥ /
śakty-ṛṣṭibhir bhuśuṇḍībhiś citra-vājaiḥ śarair api
11. abhyavarṣan prakupitāḥ sarathaṃ saha-sārathim /
icchantas tat pratīkartum ayutānāṃ trayodaśa
12. auttānapādiḥ sa tadā śastra-varṣeṇa bhūriṇā /
na evādṛśyatācchanna āsāreṇa yathā giriḥ
13. hāhā-kāras tadaivāsīt siddhānāṃ divi paśyatām /
hato 'yaṃ mānavaḥ sūryo magnaḥ puṇya-janārṇave
14. nadatsu yātudhāneṣu jaya-kāśiṣv atho mṛdhe /
udatiṣṭhad rathas tasya nīhārād iva bhāskaraḥ
15. dhanur visphūrjayan divyaṃ dviṣatāṃ khedam udvahan /
astraughaṃ vyadhamad bāṇair ghanānīkam ivānilaḥ
16. tasya te cāpa-nirmuktā bhittvā varmāṇi rakṣasām /
kāyān āviviśus tigmā girīn aśanayo yathā
17. bhallaiḥ sañchidyamānānāṃ śirobhiś cāru-kuṇḍalaiḥ /
ūrubhir hema-tālābhair dorbhir valaya-valgubhiḥ
18. hāra-keyūra-mukuṭair uṣṇīṣaiś ca mahā-dhanaiḥ /
āstṛtās tā raṇa-bhuvo rejur vīra-mano-harāḥ
19. hatāvaśiṣṭā itare raṇājirād rakṣo-gaṇāḥ kṣatriya-varya-sāyakaiḥ /
prāyo vivṛkṇāvayavā vidudruvur mṛgendra-vikrīḍita-yūthapā iva
20. apaśyamānaḥ sa tadātatāyinaṃ mahā-mṛdhe kañcana mānavottamaḥ /
purīṃ didṛkṣann api nāviśad dviṣāṃ na māyināṃ veda cikīrṣitaṃ janaḥ
21. iti bruvaṃś citra-rathaḥ sva-sārathiṃ yattaḥ pareṣāṃ pratiyoga-śaṅkitaḥ /
śuśrāva śabdaṃ jaladher iveritaṃ nabhasvato dikṣu rajo 'nvadṛśyata
22. kṣaṇenācchāditaṃ vyoma ghanānīkena sarvataḥ /
visphurat-taḍitā dikṣu trāsayat-stanayitnunā
23. vavṛṣū rudhiraughāsṛk- pūya-viṇ-mūtra-medasaḥ /
nipetur gaganād asya kabandhāny agrato 'nagha
24. tataḥ khe 'dṛśyata girir nipetuḥ sarvato-diśam /
gadā-parigha-nistriṃśa- musalāḥ sāśma-varṣiṇaḥ
25. ahayo 'śani-niḥśvāsā vamanto 'gniṃ ruṣākṣibhiḥ /
abhyadhāvan gajā mattāḥ siṃha-vyāghrāś ca yūthaśaḥ
26. samudra ūrmibhir bhīmaḥ plāvayan sarvato bhuvam /
āsasāda mahā-hrādaḥ kalpānta iva bhīṣaṇaḥ
27. evaṃ-vidhāny anekāni trāsanāny amanasvinām /
sasṛjus tigma-gataya āsuryā māyayāsurāḥ
28. dhruve prayuktām asurais tāṃ māyām atidustarām /
niśamya tasya munayaḥ śam āśaṃsan samāgatāḥ
