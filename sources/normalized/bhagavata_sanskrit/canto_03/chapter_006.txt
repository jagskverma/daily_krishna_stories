1. kāla-sañjñāṃ tadā devīṃ bibhrac-chaktim urukramaḥ /
trayoviṃśati tattvānāṃ gaṇaṃ yugapad āviśat
2. so 'nupraviṣṭo bhagavāṃś ceṣṭārūpeṇa taṃ gaṇam /
bhinnaṃ saṃyojayām āsa suptaṃ karma prabodhayan
3. prabuddha-karma daivena trayoviṃśatiko gaṇaḥ /
prerito 'janayat svābhir mātrābhir adhipūruṣam
4. pareṇa viśatā svasmin mātrayā viśva-sṛg-gaṇaḥ /
cukṣobhānyonyam āsādya yasmin lokāś carācarāḥ
5. hiraṇmayaḥ sa puruṣaḥ sahasra-parivatsarān /
āṇḍa-kośa uvāsāpsu sarva-sattvopabṛṃhitaḥ
6. sa vai viśva-sṛjāṃ garbho deva-karmātma-śaktimān /
vibabhājātmanātmānam ekadhā daśadhā tridhā
7. eṣa hy aśeṣa-sattvānām ātmāṃśaḥ paramātmanaḥ /
ādyo 'vatāro yatrāsau bhūta-grāmo vibhāvyate
8. sādhyātmaḥ sādhidaivaś ca sādhibhūta iti tridhā /
virāṭ prāṇo daśa-vidha ekadhā hṛdayena ca
9. smaran viśva-sṛjām īśo vijñāpitam adhokṣajaḥ /
virājam atapat svena tejasaiṣāṃ vivṛttaye
10. atha tasyābhitaptasya katidhāyatanāni ha /
nirabhidyanta devānāṃ tāni me gadataḥ śṛṇu
11. tasyāgnir āsyaṃ nirbhinnaṃ loka-pālo 'viśat padam /
vācā svāṃśena vaktavyaṃ yayāsau pratipadyate
12. nirbhinnaṃ tālu varuṇo loka-pālo 'viśad dhareḥ /
jihvayāṃśena ca rasaṃ yayāsau pratipadyate
13. nirbhinne aśvinau nāse viṣṇor āviśatāṃ padam /
ghrāṇenāṃśena gandhasya pratipattir yato bhavet
14. nirbhinne akṣiṇī tvaṣṭā loka-pālo 'viśad vibhoḥ /
cakṣuṣāṃśena rūpāṇāṃ pratipattir yato bhavet
15. nirbhinnāny asya carmāṇi loka-pālo 'nilo 'viśat /
prāṇenāṃśena saṃsparśaṃ yenāsau pratipadyate
16. karṇāv asya vinirbhinnau dhiṣṇyaṃ svaṃ viviśur diśaḥ /
śrotreṇāṃśena śabdasya siddhiṃ yena prapadyate
17. tvacam asya vinirbhinnāṃ viviśur dhiṣṇyam oṣadhīḥ /
aṃśena romabhiḥ kaṇḍūṃ yair asau pratipadyate
18. meḍhraṃ tasya vinirbhinnaṃ sva-dhiṣṇyaṃ ka upāviśat /
retasāṃśena yenāsāv ānandaṃ pratipadyate
19. gudaṃ puṃso vinirbhinnaṃ mitro lokeśa āviśat /
pāyunāṃśena yenāsau visargaṃ pratipadyate
20. hastāv asya vinirbhinnāv indraḥ svar-patir āviśat /
vārtayāṃśena puruṣo yayā vṛttiṃ prapadyate
21. pādāv asya vinirbhinnau lokeśo viṣṇur āviśat /
gatyā svāṃśena puruṣo yayā prāpyaṃ prapadyate
22. buddhiṃ cāsya vinirbhinnāṃ vāg-īśo dhiṣṇyam āviśat /
bodhenāṃśena boddhavyam pratipattir yato bhavet
23. hṛdayaṃ cāsya nirbhinnaṃ candramā dhiṣṇyam āviśat /
manasāṃśena yenāsau vikriyāṃ pratipadyate
24. ātmānaṃ cāsya nirbhinnam abhimāno 'viśat padam /
karmaṇāṃśena yenāsau kartavyaṃ pratipadyate
25. sattvaṃ cāsya vinirbhinnaṃ mahān dhiṣṇyam upāviśat /
cittenāṃśena yenāsau vijñānaṃ pratipadyate
26. śīrṣṇo 'sya dyaur dharā padbhyāṃ khaṃ nābher udapadyata /
guṇānāṃ vṛttayo yeṣu pratīyante surādayaḥ
27. ātyantikena sattvena divaṃ devāḥ prapedire /
dharāṃ rajaḥ-svabhāvena paṇayo ye ca tān anu
28. tārtīyena svabhāvena bhagavan-nābhim āśritāḥ /
ubhayor antaraṃ vyoma ye rudra-pārṣadāṃ gaṇāḥ
29. mukhato 'vartata brahma puruṣasya kurūdvaha /
yas tūnmukhatvād varṇānāṃ mukhyo 'bhūd brāhmaṇo guruḥ
30. bāhubhyo 'vartata kṣatraṃ kṣatriyas tad anuvrataḥ /
yo jātas trāyate varṇān pauruṣaḥ kaṇṭaka-kṣatāt
31. viśo 'vartanta tasyorvor loka-vṛttikarīr vibhoḥ /
vaiśyas tad-udbhavo vārtāṃ nṛṇāṃ yaḥ samavartayat
32. padbhyāṃ bhagavato jajñe śuśrūṣā dharma-siddhaye /
tasyāṃ jātaḥ purā śūdro yad-vṛttyā tuṣyate hariḥ
33. ete varṇāḥ sva-dharmeṇa yajanti sva-guruṃ harim /
śraddhayātma-viśuddhy-arthaṃ yaj-jātāḥ saha vṛttibhiḥ
34. etat kṣattar bhagavato daiva-karmātma-rūpiṇaḥ /
kaḥ śraddadhyād upākartuṃ yogamāyā-balodayam
35. tathāpi kīrtayāmy aṅga yathā-mati yathā-śrutam /
kīrtiṃ hareḥ svāṃ sat-kartuṃ giram anyābhidhāsatīm
36. ekānta-lābhaṃ vacaso nu puṃsāṃ suśloka-mauler guṇa-vādam āhuḥ /
śruteś ca vidvadbhir upākṛtāyāṃ kathā-sudhāyām upasamprayogam
37. ātmano 'vasito vatsa mahimā kavinādinā /
saṃvatsara-sahasrānte dhiyā yoga-vipakkayā
38. ato bhagavato māyā māyinām api mohinī /
yat svayaṃ cātma-vartmātmā na veda kim utāpare
39. yato 'prāpya nyavartanta vācaś ca manasā saha /
ahaṃ cānya ime devās tasmai bhagavate namaḥ
