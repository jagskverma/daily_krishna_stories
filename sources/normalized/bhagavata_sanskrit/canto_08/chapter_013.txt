1. ikṣvākurnabhagaścaiva dhṛṣṭaḥ śaryātireva ca /
nariṣyanto 'tha nābhāgaḥ saptamo diṣṭa ucyate
2. tarūṣaśca pṛṣadhraśca daśamo vasumān smṛtaḥ /
manorvaivasvatasyaite daśaputrāḥ parantapa
3. ādityā vasavo rudrā viśvedevā marudgaṇāḥ /
aśvināvṛbhavo rājannindrasteṣāṃ purandaraḥ
4. kaśyapo 'trirvasiṣṭhaśca viśvāmitro 'tha gautamaḥ /
jamadagnirbharadvāja iti saptarṣayaḥ smṛtāḥ
5. atrāpi bhagavajjanma kaśyapādaditerabhūt /
ādityānāmavarajo viṣṇurvāmanarūpadhṛk
6. saṅkṣepato mayoktāni saptamanvantarāṇi te /
bhaviṣyāṇy atha vakṣyāmi viṣṇoḥ śaktyānvitāni ca
7. vivasvataśca dve jāye viśvakarmasute ubhe /
saṃjñā chāyā ca rājendra ye prāg abhihite tava
8. tṛtīyāṃ vaḍavāmeke tāsāṃ saṃjñāsutāstrayaḥ /
yamo yamī śrāddhadevaśchāyāyāśca sutān chṛṇu
9. sāvarṇistapatī kanyā bhāryā saṃvaraṇasya yā /
śanaiścarastṛtīyo 'bhūdaśvinau vaḍavātmajau
10. aṣṭame 'ntara āyāte sāvarṇirbhavitā manuḥ /
nirmokavirajaskādyāḥ sāvarṇitanayā nṛpa
11. tatra devāḥ sutapaso virajā amṛtaprabhāḥ /
teṣāṃ virocanasuto balirindro bhaviṣyati
12. dattvemāṃ yācamānāya viṣṇave yaḥ padatrayam /
rāddhamindrapadaṃ hitvā tataḥ siddhimavāpsyati
13. yo 'sau bhagavatā baddhaḥ prītena sutale punaḥ /
niveśito 'dhike svargādadhunāste svarāḍ iva
14. gālavo dīptimān rāmo droṇaputraḥ kṛpastathā /
ṛṣyaśṛṅgaḥ pitāsmākaṃ bhagavān bādarāyaṇaḥ
15. ime saptarṣayastatra bhaviṣyanti svayogataḥ /
idānīmāsate rājan sve sva āśramamaṇḍale
16. devaguhyāt sarasvatyāṃ sārvabhauma iti prabhuḥ /
sthānaṃ purandarāddhṛtvā balaye dāsyatīśvaraḥ
17. navamo dakṣasāvarṇirmanurvaruṇasambhavaḥ /
bhūtaketurdīptaketurity ādyāstatsutā nṛpa
18. pārāmarīcigarbhādyā devā indro 'dbhutaḥ smṛtaḥ /
dyutimatpramukhāstatra bhaviṣyanty ṛṣayastataḥ
19. āyuṣmato 'mbudhārāyāmṛṣabho bhagavatkalā /
bhavitā yena saṃrāddhāṃ trilokīṃ bhokṣyate 'dbhutaḥ
20. daśamo brahmasāvarṇirupaślokasuto manuḥ /
tatsutā bhūriṣeṇādyā haviṣmat pramukhā dvijāḥ
21. haviṣmān sukṛtaḥ satyo jayo mūrtistadā dvijāḥ /
suvāsanaviruddhādyā devāḥ śambhuḥ sureśvaraḥ
22. viṣvakseno viṣūcyāṃ tu śambhoḥ sakhyaṃ kariṣyati /
jātaḥ svāṃśena bhagavān gṛhe viśvasṛjo vibhuḥ
23. manurvai dharmasāvarṇirekādaśama ātmavān /
anāgatāstatsutāśca satyadharmādayo daśa
24. vihaṅgamāḥ kāmagamā nirvāṇarucayaḥ surāḥ /
indraśca vaidhṛtasteṣāmṛṣayaścāruṇādayaḥ
25. āryakasya sutastatra dharmaseturiti smṛtaḥ /
vaidhṛtāyāṃ hareraṃśastrilokīṃ dhārayiṣyati
26. bhavitā rudrasāvarṇī rājan dvādaśamo manuḥ /
devavān upadevaśca devaśreṣṭhādayaḥ sutāḥ
27. ṛtadhāmā ca tatrendro devāśca haritādayaḥ /
ṛṣayaśca tapomūrtistapasvy āgnīdhrakādayaḥ
28. svadhāmākhyo hareraṃśaḥ sādhayiṣyati tanmanoḥ /
antaraṃ satyasahasaḥ sunṛtāyāḥ suto vibhuḥ
29. manustrayodaśo bhāvyo devasāvarṇirātmavān /
citrasenavicitrādyā devasāvarṇidehajāḥ
30. devāḥ sukarmasutrāma saṃjñā indro divaspatiḥ /
nirmokatattvadarśādyā bhaviṣyanty ṛṣayastadā
31. devahotrasya tanaya upahartā divaspateḥ /
yogeśvaro hareraṃśo bṛhatyāṃ sambhaviṣyati
32. manurvā indrasāvarṇiścaturdaśama eṣyati /
urugambhīrabudhādyā indrasāvarṇivīryajāḥ
33. pavitrāścākṣuṣā devāḥ śucirindro bhaviṣyati /
agnirbāhuḥ śuciḥ śuddho māgadhādyāstapasvinaḥ
34. satrāyaṇasya tanayo bṛhadbhānustadā hariḥ /
vitānāyāṃ mahārāja kriyātantūn vitāyitā
35. rājaṃścaturdaśaitāni trikālānugatāni te /
proktāny ebhirmitaḥ kalpo yugasāhasraparyayaḥ
