1. daśa dharmāya kāyādāddviṣaṭ triṇava cendave /
bhūtāṅgiraḥkṛśāśvebhyo dve dve tārkṣyāya cāparāḥ
2. nāmadheyāny amūṣāṃ tvaṃ sāpatyānāṃ ca me śṛṇu /
yāsāṃ prasūtiprasavairlokā āpūritāstrayaḥ
3. bhānurlambā kakudyāmirviśvā sādhyā marutvatī /
vasurmuhūrtā saṅkalpā dharmapatnyaḥ sutāñ śṛṇu
4. bhānostu devaṛṣabha indrasenastato nṛpa /
vidyota āsīl lambāyāstataśca stanayitnavaḥ
5. kakudaḥ saṅkaṭastasya kīkaṭastanayo yataḥ /
bhuvo durgāṇi yāmeyaḥ svargo nandistato 'bhavat
6. viśvedevāstu viśvāyā aprajāṃstān pracakṣate /
sādhyogaṇaśca sādhyāyā arthasiddhistu tatsutaḥ
7. marutvāṃśca jayantaśca marutvatyā babhūvatuḥ /
jayanto vāsudevāṃśa upendra iti yaṃ viduḥ
8. mauhūrtikā devagaṇā muhūrtāyāśca jajñire /
ye vai phalaṃ prayacchanti bhūtānāṃ svasvakālajam
9. saṅkalpāyāstu saṅkalpaḥ kāmaḥ saṅkalpajaḥ smṛtaḥ /
vasavo 'ṣṭau vasoḥ putrāsteṣāṃ nāmāni me śṛṇu
10. droṇaḥ prāṇo dhruvo 'rko 'gnirdoṣo vāsturvibhāvasuḥ /
droṇasyābhimateḥ patnyā harṣaśokabhayādayaḥ
11. prāṇasyorjasvatī bhāryā saha āyuḥ purojavaḥ /
dhruvasya bhāryā dharaṇirasūta vividhāḥ puraḥ
12. arkasya vāsanā bhāryā putrāstarṣādayaḥ smṛtāḥ /
agnerbhāryā vasordhārā putrā draviṇakādayaḥ
13. skandaśca kṛttikāputro ye viśākhādayastataḥ /
doṣasya śarvarīputraḥ śiśumāro hareḥ kalā
14. vāsorāṅgirasīputro viśvakarmākṛtīpatiḥ /
tato manuścākṣuṣo 'bhūdviśve sādhyā manoḥ sutāḥ
15. vibhāvasorasūtoṣā vyuṣṭaṃ rociṣamātapam /
pañcayāmo 'tha bhūtāni yena jāgrati karmasu
16. sarūpāsūta bhūtasya bhāryā rudrāṃśca koṭiśaḥ /
raivato 'jo bhavo bhīmo vāma ugro vṛṣākapiḥ
17. ajaikapādahirbradhno bahurūpo mahān iti /
rudrasya pārṣadāścānye ghorāḥ pretavināyakāḥ
18. prajāpateraṅgirasaḥ svadhā patnī pitṝn atha /
atharvāṅgirasaṃ vedaṃ putratve cākarot satī
19. kṛśāśvo 'rciṣi bhāryāyāṃ dhūmaketumajījanat /
dhiṣaṇāyāṃ vedaśiro devalaṃ vayunaṃ manum
20. tārkṣyasya vinatā kadrūḥ pataṅgī yāminīti ca /
pataṅgy asūta patagān yāminī śalabhān atha
21. suparṇāsūta garuḍaṃ sākṣādyajñeśavāhanam /
sūryasūtamanūruṃ ca kadrūrnāgān anekaśaḥ
22. kṛttikādīni nakṣatrāṇ īndoḥ patnyastu bhārata /
dakṣaśāpāt so 'napatyastāsu yakṣmagrahārditaḥ
23. punaḥ prasādya taṃ somaḥ kalā lebhe kṣaye ditāḥ /
śṛṇu nāmāni lokānāṃ mātṝṇāṃ śaṅkarāṇi ca
24. atha kaśyapapatnīnāṃ yatprasūtamidaṃ jagat /
aditirditirdanuḥ kāṣṭhā ariṣṭā surasā ilā
25. muniḥ krodhavaśā tāmrā surabhiḥ saramā timiḥ /
timeryādogaṇā āsan śvāpadāḥ saramāsutāḥ
26. surabhermahiṣā gāvo ye cānye dviśaphā nṛpa /
tāmrāyāḥ śyenagṛdhrādyā munerapsarasāṃ gaṇāḥ
27. dandaśūkādayaḥ sarpā rājan krodhavaśātmajāḥ /
ilāyā bhūruhāḥ sarve yātudhānāśca saurasāḥ
28. ariṣṭāyāstu gandharvāḥ kāṣṭhāyā dviśaphetarāḥ /
sutā danorekaṣaṣṭisteṣāṃ prādhānikāñ śṛṇu
29. dvimūrdhā śambaro 'riṣṭo hayagrīvo vibhāvasuḥ /
ayomukhaḥ śaṅkuśirāḥ svarbhānuḥ kapilo 'ruṇaḥ
30. pulomā vṛṣaparvā ca ekacakro 'nutāpanaḥ /
dhūmrakeśo virūpākṣo vipracittiśca durjayaḥ
31. svarbhānoḥ suprabhāṃ kanyāmuvāha namuciḥ kila /
vṛṣaparvaṇastu śarmiṣṭhāṃ yayātirnāhuṣo balī
32. vaiśvānarasutā yāśca catasraścārudarśanāḥ /
upadānavī hayaśirā pulomā kālakā tathā
33. upadānavīṃ hiraṇyākṣaḥ kraturhayaśirāṃ nṛpa /
pulomāṃ kālakāṃ ca dve vaiśvānarasute tu kaḥ
34. upayeme 'tha bhagavān kaśyapo brahmacoditaḥ /
paulomāḥ kālakeyāśca dānavā yuddhaśālinaḥ
35. tayoḥ ṣaṣṭisahasrāṇi yajñaghnāṃste pituḥ pitā /
jaghāna svargato rājanneka indrapriyaṅkaraḥ
36. vipracittiḥ siṃhikāyāṃ śataṃ caikamajījanat /
rāhujyeṣṭhaṃ ketuśataṃ grahatvaṃ ya upāgatāḥ
37. athātaḥ śrūyatāṃ vaṃśo yo 'diteranupūrvaśaḥ /
yatra nārāyaṇo devaḥ svāṃśenāvātaradvibhuḥ
38. vivasvān aryamā pūṣā tvaṣṭātha savitā bhagaḥ /
dhātā vidhātā varuṇo mitraḥ śatru urukramaḥ
39. vivasvataḥ śrāddhadevaṃ saṃjñāsūyata vai manum /
mithunaṃ ca mahābhāgā yamaṃ devaṃ yamīṃ tathā /
saiva bhūtvātha vaḍavā nāsatyau suṣuve bhuvi
40. chāyā śanaiścaraṃ lebhe sāvarṇiṃ ca manuṃ tataḥ /
kanyāṃ ca tapatīṃ yā vai vavre saṃvaraṇaṃ patim
41. aryamṇo mātṛkā patnī tayoścarṣaṇayaḥ sutāḥ /
yatra vai mānuṣī jātirbrahmaṇā copakalpitā
42. pūṣānapatyaḥ piṣṭādo bhagnadanto 'bhavat purā /
yo 'sau dakṣāya kupitaṃ jahāsa vivṛtadvijaḥ
43. tvaṣṭurdaityātmajā bhāryā racanā nāma kanyakā /
sanniveśastayorjajñe viśvarūpaśca vīryavān
44. taṃ vavrire suragaṇā svasrīyaṃ dviṣatāmapi /
vimatena parityaktā guruṇāṅgirasena yat
