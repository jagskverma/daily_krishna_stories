## Primary source passage(s)
### Srimad Bhagavata Purana (Sanskrit, GRETIL) 10.53 (20-52)
20. balena mahatā sārdhaṃ bhrātṛ-sneha-pariplutaḥ /
21. bhīṣma-kanyā varārohā kāṅkṣanty āgamanaṃ hareḥ /
22. aho tri-yāmāntarita udvāho me 'lpa-rādhasaḥ /
23. api mayy anavadyātmā dṛṣṭvā kiñcij jugupsitam /
24. durbhagāyā na me dhātā nānukūlo maheśvaraḥ /
25. evaṃ cintayatī bālā govinda-hṛta-mānasā /
26. evaṃ vadhvāḥ pratīkṣantyā govindāgamanaṃ nṛpa /
27. atha kṛṣṇa-vinirdiṣṭaḥ sa eva dvija-sattamaḥ /
28. sā taṃ prahṛṣṭa-vadanam avyagrātma-gatiṃ satī /
29. tasyā āvedayat prāptaṃ śaśaṃsa yadu-nandanam /
30. tam āgataṃ samājñāya vaidarbhī hṛṣṭa-mānasā /
31. prāptau śrutvā sva-duhitur udvāha-prekṣaṇotsukau /
32. madhu-parkam upānīya vāsāṃsi virajāṃsi saḥ /
33. tayor niveśanaṃ śrīmad upākalpya mahā-matiḥ /
34. evaṃ rājñāṃ sametānāṃ yathā-vīryaṃ yathā-vayaḥ /
35. kṛṣṇam āgatam ākarṇya vidarbha-pura-vāsinaḥ /
36. asyaiva bhāryā bhavituṃ rukmiṇy arhati nāparā /
37. kiñcit su-caritaṃ yan nas tena tuṣṭas tri-loka-kṛt /
38. evaṃ prema-kalā-baddhā vadanti sma puraukasaḥ /
39. padbhyāṃ viniryayau draṣṭuṃ bhavānyāḥ pāda-pallavam /
40. yata-vāṅ mātṛbhiḥ sārdhaṃ sakhībhiḥ parivāritā /
41. nānopahāra balibhir vāramukhyāḥ sahasraśaḥ /
42. gāyantyaś ca stuvantaś ca gāyakā vādya-vādakāḥ /
43. āsādya devī-sadanaṃ dhauta-pāda-karāmbujā /
44. tāṃ vai pravayaso bālāṃ vidhi-jñā vipra-yoṣitaḥ /
45. namasye tvāmbike 'bhīkṣṇaṃ sva-santāna-yutāṃ śivām /
46. adbhir gandhākṣatair dhūpair vāsaḥ-sraṅ-mālya bhūṣaṇaiḥ /
47. vipra-striyaḥ patimatīs tathā taiḥ samapūjayat /
48. tasyai striyas tāḥ pradaduḥ śeṣāṃ yuyujur āśiṣaḥ /
49. muni-vratam atha tyaktvā niścakrāmāmbikā-gṛhāt /
50. tāṃ deva-māyām iva dhīra-mohinīṃ su-madhyamāṃ kuṇḍala-maṇḍitānanām /
51. śuci-smitāṃ bimba-phalādhara-dyuti- śoṇāyamāna-dvija-kunda-kuḍmalām /
52. vilokya vīrā mumuhuḥ samāgatā yaśasvinas tat-kṛta-hṛc-chayārditāḥ /
