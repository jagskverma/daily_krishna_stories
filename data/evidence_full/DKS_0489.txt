## Primary source passage(s)
### Srimad Bhagavata Purana (Sanskrit, GRETIL) 1.11 (1-33)
1. sa uccakāśe dhavalodaro daro 'pyurukramasyādharaśoṇaśoṇimā /
2. tam upaśrutya ninadaṃ jagadbhayabhayāvaham /
3. tatropanītabalayo raverdīpam ivādṛtāḥ /
4. prītyutphullamukhāḥ procurharṣagadgadayā girā /
5. natāḥ sma te nātha sadāṅghripaṅkajaṃ viriñcavairiñcyasurendravanditam /
6. bhavāya nastvaṃ bhava viśvabhāvana tvam eva mātātha suhṛtpatiḥ pitā /
7. aho sanāthā bhavatā sma yadvayaṃ traiviṣṭapānām api dūradarśanam /
8. yarhyambujākṣāpasasāra bho bhavān kurūn madhūn vātha suhṛddidṛkṣayā /
9. kathaṃ vayaṃ nātha ciroṣite tvayi prasannadṛṣṭyākhilatāpaśoṣaṇam /
10. iti codīritā vācaḥ prajānāṃ bhaktavatsalaḥ /
11. madhubhojadaśārhārhakukurāndhakavṛṣṇibhiḥ /
12. sarvartusarvavibhavapuṇyavṛkṣalatāśramaiḥ /
13. gopuradvāramārgeṣu kṛtakautukatoraṇām /
14. sammārjitamahāmārga rathyāpaṇakacatvarām /
15. dvāri dvāri gṛhāṇāṃ ca dadhyakṣataphalekṣubhiḥ /
16. niśamya preṣṭham āyāntaṃ vasudevo mahāmanāḥ /
17. pradyumnaścārudeṣṇaśca sāmbo jāmbavatīsutaḥ /
18. vāraṇendraṃ puraskṛtya brāhmaṇaiḥ sasumaṅgalaiḥ /
19. vāramukhyāśca śataśo yānaistaddarśanotsukāḥ /
20. naṭanartakagandharvāḥ sūtamāgadhavandinaḥ /
21. bhagavāṃstatra bandhūnāṃ paurāṇām anuvartinām /
22. prahvābhivādanāśleṣakarasparśasmitekṣaṇaiḥ /
23. svayaṃ ca gurubhirvipraiḥ sadāraiḥ sthavirairapi /
24. rājamārgaṃ gate kṛṣṇe dvārakāyāḥ kulastriyaḥ /
25. nityaṃ nirīkṣamāṇānāṃ yadapi dvārakaukasām /
26. śriyo nivāso yasyoraḥ pānapātraṃ mukhaṃ dṛśām /
27. sitātapatravyajanairupaskṛtaḥ prasūnavarṣairabhivarṣitaḥ pathi /
28. praviṣṭastu gṛhaṃ pitroḥ pariṣvaktaḥ svamātṛbhiḥ /
29. tāḥ putram aṅkam āropya snehasnutapayodharāḥ /
30. athāviśat svabhavanaṃ sarvakāmam anuttamam /
31. patnyaḥ patiṃ proṣya gṛhānupāgataṃ vilokya sañjātamanomahotsavāḥ /
32. tam ātmajairdṛṣṭibhirantarātmanā durantabhāvāḥ parirebhire patim /
33. yadyapyasau pārśvagato rahogatas tathāpi tasyāṅghriyugaṃ navaṃ navam /
